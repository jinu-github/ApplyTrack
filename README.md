# ApplyTrack

A desktop job application tracker built with React, Vite, Electron, and Electron Builder.

## Start in development

```bash
npm install
npm run dev
```

## Build the React app

```bash
npm run build
```

## Package as a desktop installer

```bash
npm run dist
```

## Current implementation

- Dashboard
- Add application modal
- Application list with search and status filters
- Application details
- Status tracking with activity timeline
- Local persistence using localStorage
- Responsive desktop layout
- Kanban board layout

## Next implementation steps

- Drag-and-drop Kanban cards
- Real calendar
- Interview records
- Reminder system and desktop notifications
- Better note editor
- Replace localStorage with a dedicated local database if needed
